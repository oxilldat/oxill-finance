# Changelog

All notable changes to Oxill Finance are documented in this file.

## 1.0.5 — 2026-10-26

- Added separate storage folder settings for operations, accounts, and planned expenses.
- Kept existing finance notes discoverable after changing a destination folder.
- Added safe defaults and path normalization for migrated or incomplete settings.

## 1.0.4 — 2026-10-26

- Removed the duplicate background and spacing from the author contact card.

## 1.0.3 — 2026-10-26

- Made the author card compact and aligned it with the settings cards.
- Normalized the action button widths in the settings screen.
- Fixed the sizing and alignment of the social buttons on desktop and mobile.

## 1.0.2 — 2026-10-24

- Moved category legend colors from an inline CSS property to fixed CSS classes.

## 1.0.1 — 2026-10-24

- Fixed Obsidian community scanner errors for view cleanup and static style assignment.
- Migrated settings to the Obsidian 1.13 declarative settings API.
- Made note deletion respect the user's configured trash preference.
- Hardened frontmatter access and removed unnecessary type assertions.
- Added GitHub release automation with signed artifact provenance attestations.

## 1.0.0 — 2026-10-24

- Added a responsive financial overview with configurable periods and custom date ranges.
- Added Markdown-backed income, expenses, accounts, and transfers.
- Added configurable categories and safe category deletion with mandatory note migration.
- Added a yearly planning heatmap and planned-expense workflow.
- Added Russian and English interfaces with light and dark theme support.
- Added compact, responsive layouts for desktop and mobile Obsidian.
